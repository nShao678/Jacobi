This repo contains scripts to reproduce the numerical experiments in [1].

To reproduce Figure 1, run test_hist.

To reproduce Figure 2, run test_evp.

To reproduce Figure 3, run test_hilb.

[1]: Nian Shao and Yuji Nakatsukasa. Accelerating preconditioned Jacobi methods via perturbation-inspired pivoting. arXiv:2607.23187
